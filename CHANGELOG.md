# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-14

### Added
- Initial release of OSINT Hub.
- Support for 21 OSINT tools across various categories.
- Modern GUI built with CustomTkinter.
- Comprehensive CLI for advanced users and scripting.
- Automated tool installation and management system.
- Results database with export support (JSON, CSV, TXT, HTML).
- Configuration persistence.
- Desktop integration scripts.
- Community guidelines (Code of Conduct, Contributing, Security Policy).
